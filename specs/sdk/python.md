# Python SDK Contract

Canonical interface: see `typescript.md` — identical across languages.

## Python idiom

```python
class AIDosClient:
    async def chat_complete(self, request: ChatRequest) -> ChatResponse: ...
    def chat_stream(self, request: ChatRequest) -> AsyncIterator[ChatChunk]: ...
    async def embeddings_create(self, request: EmbeddingRequest) -> EmbeddingResponse: ...
    async def images_generate(self, request: ImageRequest) -> ImageResponse: ...
    async def audio_transcribe(self, request: TranscriptionRequest) -> TranscriptionResponse: ...
    async def audio_synthesize(self, request: SynthesisRequest) -> SynthesisResponse: ...
    async def videos_generate(self, request: VideoRequest) -> Job: ...
    async def models_list(self, filter: ModelFilter | None = None) -> list[Model]: ...
    async def models_find_compatible(self, model_id: str, requirements: CompatibilityRequirements) -> list[Model]: ...
```

- **Errors**: raised exception hierarchy, `AIDosError` base — the same taxonomy as the adapter contract's own `ProviderError` subclasses, since this SDK is a thin client around the same Gateway that taxonomy was designed for.
- **Config**: constructor kwargs — `AIDosClient(api_key=..., base_url=...)`.
- **Naming**: snake_case throughout, the one deliberate surface difference from the canonical shape's dotted-namespace style — Python's own convention, not a contract change.
- **Types**: Pydantic models generated from `../schemas/*.schema.json` — the same models this system's own backend uses internally, not a re-derivation.
